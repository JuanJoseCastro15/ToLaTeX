
Ejemplo de Caso de Uso 
Nombre de Caso de Uso:  Desplegar menú inicial 
Resumen: Como usuario se necesita una  pantalla inicial donde se mira un botón para tomar foto. 

Actor:   Usuario
 
Precondición:  Tener instalada la aplicación. 

Descripción: 
1.Buscar la aplicación en el teléfono.
2.Presionar el icono de la aplicación.
3.Cargar la aplicación.
4.Desplegar el menú inicial de la aplicación.
5.En el menú inicial,  mostrar un botón con una imagen y un texto que diga “Tomar foto”.
6.El usuario presiona el botón.
